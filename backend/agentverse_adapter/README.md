# CrisisFlow Agentverse Adapter

This small FastAPI process is the Agentverse-facing boundary for the existing
Node/Express backend. It follows the current Agentverse FastAPI/uagents_core
onboarding approach; it does not replace CrisisFlow or `/api/acp`.

## Run

1. Start the Express backend on its private network address.
2. Set `AGENT_SEED_PHRASE`, `AGENT_EXTERNAL_ENDPOINT`, and
   `CRISISFLOW_BACKEND_URL` in the environment.
3. Install `requirements.txt`, then run `uvicorn main:app --host 0.0.0.0 --port 8000`.
4. Deploy this adapter at the HTTPS address in `AGENT_EXTERNAL_ENDPOINT`.
5. In Agentverse choose **Launch an Agent → Connect Agent → FastAPI**, enter
   the public adapter URL, add the repository `AGENTVERSE_README.md` content
   and the configured keywords, run the registration script generated by the
   Agentverse UI, then use **Evaluate Registration**.

The adapter exposes `GET /status` and `POST /chat`. It forwards messages to
the private `POST /api/agent/chat` bridge, which uses only CrisisFlow's
allow-listed capabilities and existing Phase 8 tool registry.

Do not expose the Express development server or credentials publicly.
